# Z Calculator v1.2.0

## Windows x64 배포

설치 마법사에서 설치 위치를 선택할 수 있습니다. 기본값은 `C:\Program Files\Z Calculator`입니다. 이전 버전 위에 그대로 설치하면 교체됩니다.

### 바뀐 표시

- **반사·전송을 S11·S21의 dB로 표시합니다.** 값은 0 dB 이하입니다. 1.1.0까지는 같은 크기를 양수 손실값(반사 손실 RL, 삽입 손실 IL)으로 표시했습니다. RL = −S11 dB, IL = −S21 dB이므로 숫자의 크기는 같고 부호만 바뀝니다. 차동쌍은 Sdd11·Sdd21입니다. 단위 길이당 전파 손실(dB/m)은 그대로 양수입니다.

### 새 기능

- **그래프 마커.** 그래프를 클릭하거나 끌면 마커가 놓이고 그 주파수와 값을 표시합니다. 오른쪽 클릭으로 지웁니다. 설계 주파수 마커와 별개이며, 그래프 항목을 바꾸거나 다시 계산해도 같은 주파수에 남습니다. 그래프 PNG와 PowerPoint 보고서(그림과 수치 표)에도 들어갑니다.
- **Touchstone 내보내기.** 위쪽 **Touchstone** 버튼이 계산한 S파라미터를 저장합니다. 단일 선로는 2포트 `.s2p`, 차동쌍은 단일 종단 4포트 `.s4p`입니다.
  - 형식은 `# Hz S RI R <기준 임피던스>`입니다. `.s4p`의 포트 기준은 차동 기준의 절반입니다(차동 100 Ω이면 포트당 50 Ω).
  - `.s4p`의 포트 번호는 저장 창의 파일 형식에서 고릅니다: **통과 1→2, 3→4**(기본, 근단이 포트 1·3) 또는 **통과 1→3, 2→4**(근단이 포트 1·2). 선택한 배치와 단면·재료·길이는 파일 머리 주석에 적힙니다.
  - 4포트에는 근단·원단 누화가 포함됩니다. 이를 위해 차동쌍의 짝수 모드를 추가로 해석합니다.

### 계산

- 차동(홀수 모드) 결과와 단일 선로 결과는 1.1.0과 같습니다.
- 도체 저항은 주파수에 따라 표피 효과를 반영합니다(직류 → √f). 매끄러운 구리 기준이며 동박 거칠기는 포함하지 않습니다. 표피 깊이가 거칠기 크기에 가까워지는 수 GHz 이상에서는 실제 도체 손실이 이보다 클 수 있습니다.

동박 거칠기·비아·커넥터 전이는 모델 적용 범위 밖입니다. 배포 파일은 코드 서명되지 않았습니다.

함께 제공하는 예제 보고서는 직접 입력 유전체(Dk 4.2, Df 0.018), 1 GHz, 100 mm, 100 Ω 차동 스트립라인의 선폭 역산 결과입니다.
