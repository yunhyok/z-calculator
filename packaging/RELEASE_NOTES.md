# Z Calculator v1.2.1

## Windows x64 배포

설치 마법사에서 설치 위치를 선택할 수 있습니다. 기본값은 `C:\Program Files\Z Calculator`입니다. 이전 버전 위에 그대로 설치하면 교체됩니다.

### Touchstone 4포트(.s4p) 포트 번호 배치

- **저장 전에 배치를 그림으로 보여 주며 묻습니다.** 1.2.0은 저장 창의 파일 형식 목록에서만 고를 수 있어 놓치기 쉬웠습니다.
- **기본 배치가 근단 포트 1·2, 원단 포트 3·4로 바뀌었습니다.** 왼쪽에 1·2, 오른쪽에 3·4가 있는 회로 도구의 4포트 기호에 그대로 연결하고, 차동쌍을 (1, 2)와 (3, 4)로 묶으면 됩니다. 다른 배치(근단 1·3, 원단 2·4)도 계속 고를 수 있고, 마지막에 쓴 배치를 기억합니다.
- 파일 머리 주석에 각 포트의 위치와 차동쌍으로 묶을 포트를 적습니다.

### 1.2.0으로 저장한 .s4p를 쓰고 있다면

1.2.0의 기본 배치(근단 1·3, 원단 2·4)로 저장한 파일을, 왼쪽 1·2 / 오른쪽 3·4 기호에 연결해 왼쪽 두 핀을 한 쌍으로 묶으면 같은 선로의 양 끝이 한 쌍이 됩니다. 이때 차동 전송(Sdd21) 자리에 누화가 표시되어 −40 dB 부근에서 촘촘하게 요동하는 곡선이 나옵니다. 파일 내용은 올바르므로 다음 중 하나로 해결됩니다.

- 1.2.1에서 기본 배치로 다시 저장합니다.
- 기존 파일을 그대로 두고 차동쌍을 포트 (1, 3)과 (2, 4)로 묶습니다.

계산 결과와 `.s2p`는 1.2.0과 같습니다.

동박 거칠기·비아·커넥터 전이는 모델 적용 범위 밖입니다. 배포 파일은 코드 서명되지 않았습니다.

함께 제공하는 예제 보고서는 직접 입력 유전체(Dk 4.2, Df 0.018), 1 GHz, 100 mm, 100 Ω 차동 스트립라인의 선폭 역산 결과입니다.
